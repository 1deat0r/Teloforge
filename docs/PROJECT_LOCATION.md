# Project location

The working checkout is the user's requested `AI Agents/Teloforge` folder and is linked to [the public GitHub repository](https://github.com/1deat0r/Teloforge). Local absolute mount paths and filesystem identifiers are not part of the public project record.

The project remains portable: clone the repository anywhere and follow `README.md` and `docs/DEVELOPMENT.md`.

The inherited project-directory guide references a lifecycle registration tool that was unavailable during folder creation. The user explicitly requested this project; no global lifecycle catalog was modified.
